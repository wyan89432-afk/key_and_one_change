# Fixed Table • 1 Change Search

This browser app searches a fixed table for 3-digit 1-change matches.

## 1-change rule
- Digit order does not matter.
- Exactly two digits are shared.
- The remaining digit changes by +1 or -1.
- Digits are circular, so 0 ↔ 9 is also one change.

## အစဉ်လိုက်
Press **အစဉ်လိုက်** to keep only ordered matches in the table's column-major order. The sequence continues from the end of one column into the next column. Matching cells are connected with blue curved arrows; the numbers themselves are not changed.
